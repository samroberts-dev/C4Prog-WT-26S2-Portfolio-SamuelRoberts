# Web Technologies Portfolio

### Phase 3: Component selection (step 2)

Source: [SCC Components](https://components.dev.screencraft.net.au/components/)

The dashboard will need the following components:

> `-` **Site Header**: Displays the portfolio title and my name.

> `-` **Vertical Cards**: Displays a description and link for each phase.

> `-` **Navigation Bar**: Provides links to Home and each phase.

> `-` **Centred Content**: Keeps the dashboard content aligned and readable.

> `-` **Site Footer**: Displays copyright information and useful links.

> `-` **Reference Cards**: Lists the resources used on the copyright page.
